# Data and code availability

This repository accompanies the manuscript:

> **Autoencoder-guided process stratification and candidate-selected diffusion augmentation for event-scale flood forecasting in a data-scarce basin**

The hydrological observations used in this study are subject to confidentiality restrictions and are not publicly available. Core implementations of the proposed framework are provided in [an anonymous repository](https://anonymous.4open.science/r/flood-forecasting-review/) for inspection during peer review. The complete source code will be made publicly available upon acceptance of the manuscript. The public code release will not include the confidential hydrological observations.

The original GitHub repository remains private during peer review. Reviewers can access the anonymous repository without a GitHub account or an individual access request. The review deposit contains the core autoencoder, K-means, DDPM and RCNN implementations; it does not yet contain the complete experimental code package.
