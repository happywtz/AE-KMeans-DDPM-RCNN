# Proposed data and code availability statement

The hydrological observations used in this study are subject to confidentiality restrictions and are not publicly available. The core implementations of the autoencoder, K-means clustering, DDPM, and residual convolutional neural network will be made publicly available on GitHub upon acceptance of the manuscript. This release will cover the core algorithm components rather than the complete experiment orchestration and reproduction package.

A repository link should be added only after the repository has been created. A private repository is not publicly accessible.
